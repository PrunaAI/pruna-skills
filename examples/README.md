# Examples

Starter prompts for public workflows. Mirrors `catalog/workflows/` layout (`core/`, `verticals/`).

```text
catalog/examples/
  workflows/
    core/
    verticals/
  tools/
    p-image-try-on/
  shared/
    realistic-persona/
```

`bundle_skill.sh` copies `example-prompt.md` from `workflows/core/` or `workflows/verticals/` into the install bundle.

Pruna-internal launch examples live in [`.mine/examples/workflows/launches/`](../../.mine/README.md).
