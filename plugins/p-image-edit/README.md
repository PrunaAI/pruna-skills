# p-image-edit

Use when the user wants to edit an existing image, change wardrobe or background, compose from reference photos, inpaint-style adjustments, or multi-image edits from a prompt.

## Install

```bash
openclaw plugins install clawhub:@pruna-ai/p-image-edit
```

Claude Code: `/plugin install p-image-edit@pruna-skills`

## Requirements

- `PRUNA_API_KEY` — [dashboard.pruna.ai](https://dashboard.pruna.ai/)
