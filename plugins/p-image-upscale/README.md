# p-image-upscale

Use when the user wants to upscale image resolution, enhance detail in an existing still, or prepare photos for print, large crops, or quality demos.

## Install

```bash
openclaw plugins install clawhub:@pruna-ai/p-image-upscale
```

Claude Code: `/plugin install p-image-upscale@pruna-skills`

## Requirements

- `PRUNA_API_KEY` — [dashboard.pruna.ai](https://dashboard.pruna.ai/)
