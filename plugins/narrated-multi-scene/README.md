# narrated-multi-scene

Use when the user needs a multi-scene narrated film, episodic B-roll story, chaptered promo, or several linked video beats with voiceover and no in-scene character dialogue.

## Install

```bash
openclaw plugins install clawhub:@pruna-ai/narrated-multi-scene
```

Claude Code: `/plugin install narrated-multi-scene@pruna-skills`

## Requirements

- `PRUNA_API_KEY` — [dashboard.pruna.ai](https://dashboard.pruna.ai/)
