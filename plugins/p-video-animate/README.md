# p-video-animate

Use when the user wants to animate a still using motion from another video, motion-transfer remixes, or performance variations from a template clip—not replacing someone inside existing footage.

## Install

```bash
openclaw plugins install clawhub:@pruna-ai/p-video-animate
```

Claude Code: `/plugin install p-video-animate@pruna-skills`

## Requirements

- `PRUNA_API_KEY` — [dashboard.pruna.ai](https://dashboard.pruna.ai/)
