# generation-quality-checklists

Use when reviewing generated images, video, or audio — run the core quality checklist and model-specific checklist before asking the user to approve stills or clips.

## Install

```bash
openclaw plugins install clawhub:@pruna-ai/generation-quality-checklists
```

Claude Code: `/plugin install generation-quality-checklists@pruna-skills`

## Requirements

- `PRUNA_API_KEY` — [dashboard.pruna.ai](https://dashboard.pruna.ai/)
