# recipe-catalog

Use when choosing a generative pipeline — mood boards, hero variants, explainers, music videos, avatar reels, and other recipe letters A–R with linked tool and workflow skills.

## Install

```bash
openclaw plugins install clawhub:@pruna-ai/recipe-catalog
```

Claude Code: `/plugin install recipe-catalog@pruna-skills`

## Requirements

- `PRUNA_API_KEY` — [dashboard.pruna.ai](https://dashboard.pruna.ai/)
