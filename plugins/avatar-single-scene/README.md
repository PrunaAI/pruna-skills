# avatar-single-scene

Use when the user needs one talking-head clip, a single host line with lip sync, or one spokesperson beat—not multi-segment host reels or motion-transfer comparison grids.

## Install

```bash
openclaw plugins install clawhub:@pruna-ai/avatar-single-scene
```

Claude Code: `/plugin install avatar-single-scene@pruna-skills`

## Requirements

- `PRUNA_API_KEY` — [dashboard.pruna.ai](https://dashboard.pruna.ai/)
