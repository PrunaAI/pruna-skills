# avatar-single-scene

Use when the user needs one talking-head beat with intake and approval gates—not a raw p-video-avatar call, multi-segment host reels (avatar-multi-scene), or motion-transfer grids.

## Install

```bash
openclaw plugins install clawhub:@pruna-ai/avatar-single-scene
```

Claude Code: `/plugin install avatar-single-scene@pruna-skills`

## Requirements

- `PRUNA_API_KEY` — [dashboard.pruna.ai](https://dashboard.pruna.ai/)
