# image-to-video

Use when the user needs one narrated or B-roll scene from stills with optional TTS—not a bare p-video API call, multi-scene film (narrated-multi-scene), or talking-head-only piece (avatar-single-scene).

## Install

```bash
openclaw plugins install clawhub:@pruna-ai/image-to-video
```

Claude Code: `/plugin install image-to-video@pruna-skills`

## Requirements

- `PRUNA_API_KEY` — [dashboard.pruna.ai](https://dashboard.pruna.ai/)
