# image-to-video

Use when the user needs one video clip from stills, a single narrated story beat, one B-roll shot, or one scene—not a full multi-scene film or talking-head-only piece.

## Install

```bash
openclaw plugins install clawhub:@pruna-ai/image-to-video
```

Claude Code: `/plugin install image-to-video@pruna-skills`

## Requirements

- `PRUNA_API_KEY` — [dashboard.pruna.ai](https://dashboard.pruna.ai/)
