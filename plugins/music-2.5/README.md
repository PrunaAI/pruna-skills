# music-2.5

Use when the user wants AI song generation with vocals, sung lyrics, original tracks from a style prompt, or source audio for a music video.

## Install

```bash
openclaw plugins install clawhub:@pruna-ai/music-2.5
```

Claude Code: `/plugin install music-2.5@pruna-skills`

## Requirements

- `PRUNA_API_KEY` — [dashboard.pruna.ai](https://dashboard.pruna.ai/)
