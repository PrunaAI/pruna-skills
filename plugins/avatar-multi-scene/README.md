# avatar-multi-scene

Use when the user needs multiple talking-head segments, motion-transfer comparison reels, mixed host and animate clips, or multi-scene UGC with character continuity.

## Install

```bash
openclaw plugins install clawhub:@pruna-ai/avatar-multi-scene
```

Claude Code: `/plugin install avatar-multi-scene@pruna-skills`

## Requirements

- `PRUNA_API_KEY` — [dashboard.pruna.ai](https://dashboard.pruna.ai/)
