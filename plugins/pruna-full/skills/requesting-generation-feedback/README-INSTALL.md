# requesting-generation-feedback

## Install

```bash
npx skills add PrunaAI/pruna-skills@requesting-generation-feedback -y
```

For a workflow with embedded tool dependencies, prefer:

```bash
npx plugins add PrunaAI/pruna-skills -y
# pick requesting-generation-feedback
```

List all skills: `npx skills add PrunaAI/pruna-skills -l`

After install, start a **new chat**. See the [root README](https://github.com/PrunaAI/pruna-skills/tree/main/workflows/core/README/SKILL.md).

## From a local clone

```bash
npx skills add .@requesting-generation-feedback -y
# or:
npx skills add ./plugins/requesting-generation-feedback/skills --skill requesting-generation-feedback -y
```
