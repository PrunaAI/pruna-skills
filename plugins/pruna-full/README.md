# pruna-full

Complete Pruna Skills bundle: all tool, router, core, and vertical skills in one plugin.

## Install

```bash
openclaw plugins install clawhub:@pruna-ai/pruna-full
```

Claude Code: `/plugin install pruna-full@pruna-skills`

## Requirements

- `PRUNA_API_KEY` — [dashboard.pruna.ai](https://dashboard.pruna.ai/)
