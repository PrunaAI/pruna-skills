# whisperx

Use when the user needs word-level lyric timestamps, cut-safe line boundaries for music videos, or alignment after song generation before editing clips.

## Install

```bash
openclaw plugins install clawhub:@pruna-ai/whisperx
```

Claude Code: `/plugin install whisperx@pruna-skills`

## Requirements

- `PRUNA_API_KEY` — [dashboard.pruna.ai](https://dashboard.pruna.ai/)
