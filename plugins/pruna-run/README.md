# pruna-run

Use when the user wants a quick single-shot generation with minimal intake—one image, video clip, or avatar call from a prompt. Do not use for multi-scene films, music videos, explainers, or when they need a recipe menu or staged approval plan.

## Install

```bash
openclaw plugins install clawhub:@pruna-ai/pruna-run
```

Claude Code: `/plugin install pruna-run@pruna-skills`

## Requirements

- `PRUNA_API_KEY` — [dashboard.pruna.ai](https://dashboard.pruna.ai/)
