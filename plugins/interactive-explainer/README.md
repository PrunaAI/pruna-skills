# interactive-explainer

Use when the user wants educational explainers with a host plus in-story characters, history or science shorts, or witness and expert dialogue—not wall-to-wall narration alone.

## Install

```bash
openclaw plugins install clawhub:@pruna-ai/interactive-explainer
```

Claude Code: `/plugin install interactive-explainer@pruna-skills`

## Requirements

- `PRUNA_API_KEY` — [dashboard.pruna.ai](https://dashboard.pruna.ai/)
