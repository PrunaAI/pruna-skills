# visual-transition-reel

Use when the user needs a visual montage, transitions between stills, action-sequence reel, or multi-scene piece where narration is optional or absent.

## Install

```bash
openclaw plugins install clawhub:@pruna-ai/visual-transition-reel
```

Claude Code: `/plugin install visual-transition-reel@pruna-skills`

## Requirements

- `PRUNA_API_KEY` — [dashboard.pruna.ai](https://dashboard.pruna.ai/)
