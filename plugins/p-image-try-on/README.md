# p-image-try-on

Use when the user wants virtual try-on, dress a person in clothing from reference photos, garment fitting on a model still, or ecommerce fashion compositing.

## Install

```bash
openclaw plugins install clawhub:@pruna-ai/p-image-try-on
```

Claude Code: `/plugin install p-image-try-on@pruna-skills`

## Requirements

- `PRUNA_API_KEY` — [dashboard.pruna.ai](https://dashboard.pruna.ai/)
