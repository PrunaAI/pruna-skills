# music-video

Use when the user wants a music video, lyric video, sung promo, or original song paired with performance and B-roll clips.

## Install

```bash
openclaw plugins install clawhub:@pruna-ai/music-video
```

Claude Code: `/plugin install music-video@pruna-skills`

## Requirements

- `PRUNA_API_KEY` — [dashboard.pruna.ai](https://dashboard.pruna.ai/)
