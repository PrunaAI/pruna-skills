# pruna-generative-pipeline

Use when the user is unsure which production workflow fits, needs a recipe menu for multi-step media projects, or wants chained image, video, and audio with approval gates.

## Install

```bash
openclaw plugins install clawhub:@pruna-ai/pruna-generative-pipeline
```

Claude Code: `/plugin install pruna-generative-pipeline@pruna-skills`

## Requirements

- `PRUNA_API_KEY` — [dashboard.pruna.ai](https://dashboard.pruna.ai/)
