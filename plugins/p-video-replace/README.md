# p-video-replace

Use when the user wants to swap a person, outfit, or product inside existing video, in-footage recast, wardrobe change, or product replacement while keeping camera motion and audio.

## Install

```bash
openclaw plugins install clawhub:@pruna-ai/p-video-replace
```

Claude Code: `/plugin install p-video-replace@pruna-skills`

## Requirements

- `PRUNA_API_KEY` — [dashboard.pruna.ai](https://dashboard.pruna.ai/)
