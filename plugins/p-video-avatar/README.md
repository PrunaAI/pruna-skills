# p-video-avatar

Use when the user wants one talking-head API call from a portrait plus script. Prefer avatar-single-scene for a full single-beat workflow with gates; prefer avatar-multi-scene for multiple host segments.

## Install

```bash
openclaw plugins install clawhub:@pruna-ai/p-video-avatar
```

Claude Code: `/plugin install p-video-avatar@pruna-skills`

## Requirements

- `PRUNA_API_KEY` — [dashboard.pruna.ai](https://dashboard.pruna.ai/)
