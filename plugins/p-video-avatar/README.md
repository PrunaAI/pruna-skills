# p-video-avatar

Use when the user wants a talking-head video, lip-synced host or spokesperson clip, on-camera performance from a portrait plus script, or narrated avatar footage.

## Install

```bash
openclaw plugins install clawhub:@pruna-ai/p-video-avatar
```

Claude Code: `/plugin install p-video-avatar@pruna-skills`

## Requirements

- `PRUNA_API_KEY` — [dashboard.pruna.ai](https://dashboard.pruna.ai/)
