# gemini-3.1-flash-tts

Use when someone needs spoken narration or voiceover — explainer tracks, documentary lines, or voice to pair with generated video.

## Install

```bash
openclaw plugins install clawhub:@pruna-ai/gemini-3.1-flash-tts
```

Claude Code: `/plugin install gemini-3.1-flash-tts@pruna-skills`

## Requirements

- `PRUNA_API_KEY` — [dashboard.pruna.ai](https://dashboard.pruna.ai/)
