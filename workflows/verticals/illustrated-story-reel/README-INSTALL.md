# illustrated-story-reel

## Install

```bash
npx skills add PrunaAI/pruna-skills@illustrated-story-reel -y
```

For a workflow with embedded tool dependencies, prefer:

```bash
npx plugins add PrunaAI/pruna-skills -y
# pick illustrated-story-reel
```

List all skills: `npx skills add PrunaAI/pruna-skills -l`

After install, start a **new chat**. See the [root README](../../../README.md).

## From a local clone

```bash
npx skills add .@illustrated-story-reel -y
# or:
npx skills add ./plugins/illustrated-story-reel/skills --skill illustrated-story-reel -y
```
