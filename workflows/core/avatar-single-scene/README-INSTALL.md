# single-scene-avatar-video

## Install

From a clone of this repository:

```bash
mkdir -p ~/.cursor/skills
cp -R /path/to/pruna-ai-content-generation-skills/catalog/workflows/core/avatar-single-scene ~/.cursor/skills/
```

Or install the whole repository with `npx skills add` (see repository root `README.md`). Restart Cursor or start a new chat.

## Expected path

```text
~/.cursor/skills/single-scene-avatar-video/SKILL.md
```
