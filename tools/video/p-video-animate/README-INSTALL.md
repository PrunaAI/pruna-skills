# p-video-animate

## Install

From a clone of this repository:

```bash
mkdir -p ~/.cursor/skills
cp -R /path/to/pruna-ai-content-generation-skills/tools/video/p-video-animate ~/.cursor/skills/
```

Or install the whole repository with `npx skills add` (see repository root `README.md`). Restart Cursor or start a new chat.

## Expected path

```text
~/.cursor/skills/p-video-animate/SKILL.md
```
