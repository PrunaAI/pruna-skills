# p-image-ideogram

Requires `REPLICATE_API_TOKEN`.

## Install from GitHub

No clone required:

```bash
npx skills add PrunaAI/pruna-skills/plugins/p-image-ideogram/skills@p-image-ideogram --agent cursor -y
```

Or:

```bash
npx skills add PrunaAI/pruna-skills/plugins/p-image-ideogram/skills --skill p-image-ideogram -y
```

See [README.md](../../../README.md#install-skills) for more URL formats.

## Install from a clone

```bash
npx skills add ./plugins/p-image-ideogram/skills --skill p-image-ideogram -y
# or:
npx skills add PrunaAI/pruna-skills/plugins/p-image-ideogram/skills --skill p-image-ideogram --agent cursor -y
```

Restart Cursor or start a new chat.

## Expected path

```text
~/.cursor/skills/p-image-ideogram/SKILL.md
```
