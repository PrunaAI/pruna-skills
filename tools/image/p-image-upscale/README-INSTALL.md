# p-image-upscale

## Install

```bash
npx skills add PrunaAI/pruna-skills@p-image-upscale -y
```

For a workflow with embedded tool dependencies, prefer:

```bash
npx plugins add PrunaAI/pruna-skills -y
# pick p-image-upscale
```

List all skills: `npx skills add PrunaAI/pruna-skills -l`

After install, start a **new chat**. See the [root README](../../../README.md).

## From a local clone

```bash
npx skills add .@p-image-upscale -y
# or:
npx skills add ./plugins/p-image-upscale/skills --skill p-image-upscale -y
```
