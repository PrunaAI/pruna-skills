# Workflow skills

Multi-step deliverable playbooks under `skills/workflows/`. The **agent is the runner** (curl + ffmpeg) — no Python scripts.

Install one workflow (plus its Prerequisites):

```bash
npx skills add PrunaAI/pruna-skills@music-video -y
```

Or everything: `npx skills add PrunaAI/pruna-skills@pruna -y`.

Human recipe map: [docs/WORKFLOW-RECIPES.md](../../docs/WORKFLOW-RECIPES.md).
